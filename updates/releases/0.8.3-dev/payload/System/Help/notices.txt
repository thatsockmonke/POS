@meshtastic-import-refused

@meshtastic-invalid-key

@meshtastic-verify-identity
Compare the full public key through another trusted channel. Forgetting accepts the next observed key; it does not authenticate the person.

@meshtastic-history-controls
Opt-in server stores up to 128 broadcasts, 198 bytes each, on the chosen channel. It never caches private DMs. Requests return up to 20 messages, at least 5 seconds apart and within normal airtime limits. Valid UTC expires records after the requested window (max 24h); without a clock, only this boot is replayed. POS prefixes original sender/ID inside freshly encrypted server-owned history replies. Cached files remain readable in Radio/store-forward when disabled.

@music-pos-music

@music-playlist-empty
Use an .m3u file with SD-root-relative user audio paths. Add tracks with P during playback.

@files-files-controls
