Type an expression and press Enter. Arrows select buttons; Enter presses the selected button. Backspace deletes. Tab opens tools. Examples: 1/3+1/6, sqrt(2), 2^3, sin(30), a=12, a/4. DEG/RAD affects trig. Use commas for functions such as ncr(5,2), root(27,3), mean(2,4,6), std(2,4,6). std uses the sample formula. Vars are saved on SD. CAS works with polynomials in x; blank x in Vars restores symbolic evaluation. Esc or global Home closes. Tab > More modes: graph, exact fractions, linear systems, matrices, units, programmer operations and saved .calc worksheets. Files opens worksheets in Calculator. Recent expressions are retained on SD.
